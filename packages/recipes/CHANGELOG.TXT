Recipes - change log
The top section is the coming version (no date): write each change below it as "- ...", in words
for the gateway owners - the Portal and the gateway show them as "What's new" before an update.
store_update.sh --package recipes publishes it (dated) and puts the next patch version on top; change
the top version by hand for a bigger step (e.g. 1.0.0). This file is not packed into the package.

0.5.14 (2026-11-05)
- Its login page uses the language you last used Recipes in

0.5.13 (2026-11-05)
- Its login page is for the application's password on your computer (gateway 1.1.24), no longer the website's
- Lists its trigger (clip), so the Portal shows its Inbox

0.5.12 (2026-11-05)
- Its description in 中文 too: the Portal and the Applications page show it in your language
- Its website can have a password (gateway 1.1.23): the login page is in the recipes' look, in English and 中文

0.5.11 (2026-11-01)
- Each of its tools has a sample (`example`): the gateway's Simulator and Send test start from it (gateway 1.1.11)

0.5.10 (2026-11-01)
- Several tags can be chosen at once: e.g. 中菜 + 湯 shows only the Chinese soups. Click a chosen tag again to
  drop it, 全部 / All for all recipes

0.5.9 (2026-11-01)
- All tags are listed under the search: click one to see only those recipes, click it again (or 全部 / All) for
  all of them. A tag on a recipe's page shows all recipes with that tag

0.5.8 (2026-11-01)
- Tags for recipes: cuisine and kind together (中菜, 意大利菜, 日式, 甜品, 糖水, 湯 ...), several per recipe. Filter the
  list by a tag (menu next to the search - also on the website, published recipes only); in the form, click
  the tags you already use. Build recipe: the assistant suggests 1-4 tags, from your existing ones when one
  fits (your own tags stay). The bot can filter and set them too; the "clip" trigger can send tags

0.5.7 (2026-10-31)
- When the page can't reach the application (e.g. BotGateway was restarted), it also tells you to open it again
  from the BotGateway app (app kit, store 1.0.3)

0.5.6 (2026-10-31)
- Save a recipe idea from anywhere: other services (a phone shortcut, a script ...) can send a title, link and
  notes to https://<its website>/hook/clip; it becomes an unpublished recipe draft. Signed with the new
  setting "Trigger secret" (empty = off); a repeat with the same X-Event-Id is saved once. With the offline
  inbox on (Portal) it also works while the computer is off. Needs BotGateway 1.1.0
