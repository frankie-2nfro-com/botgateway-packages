MyArcade - change log
The top section is the coming version (no date): write each change below it as "- ...", in words
for the gateway owners - the Portal and the gateway show them as "What's new" before an update.
store_update.sh --package myarcade publishes it (dated) and puts the next patch version on top; change
the top version by hand for a bigger step (e.g. 1.0.0). This file is not packed into the package.

0.1.12
- [Changed and non commited item put here]

0.1.11 (2026-11-25)
- 🎮 hides or shows the on-screen buttons (Up, Down, Grab ...) on a phone, in full screen and in the room; each game
  remembers the choice in that browser. A game played by touching it (e.g. dragging the pieces) gets more room
- Game makers: "touch_play": true in game.json when the game is played fully by touching it - its buttons then start
  hidden

0.1.10 (2026-11-25)
- Sound on iPhone: a game's sound now starts with the tap on Start (before, only after a tap inside the game itself,
  so sound came sometimes and sometimes not); it also plays with the phone's silent switch on (iOS 17 or newer)
- Full screen on iPhone: it follows the part of the screen really visible (Safari's bars), so the top and the ✕ are
  no longer cut off; the page keeps clear of the notch and the status bar

0.1.9 (2026-11-25)
- Full screen on a phone (iPhone): the game now fits the screen exactly and the page no longer scrolls behind it
  (the room's title row was wider than a phone screen and made the whole page wider)
- Full screen: a round ✕ at the top right leaves it, and the score floats at the top left, so the game gets the
  whole height

0.1.8 (2026-11-25)
- Full screen button in the game room: the game as large as the screen allows, black around it where the screen's
  shape differs (a wide game fills the screen); the score, Exit full screen and the touch buttons stay. On a phone
  without the browser's full screen (iPhone) the page covers the window instead

0.1.7 (2026-11-24)
- A game's frame now has the game's own shape: a portrait (phone-like) game such as Rune Rush or Lantern Well no
  longer sits in a wide box with black space beside it
- Game makers can give the shape in game.json, e.g. "aspect": "9:16" or "4:3"; without it a game looks as before

0.1.6 (2026-11-19)
- Games can use mouse look (the pointer locks after a click, Esc releases it), e.g. first-person 3D games; needs
  2nfro Desktop 1.1.31 or newer, on an older one such a game falls back to dragging
- On a Local gateway (2nfro Desktop 1.1.41: runs on this computer only, no website) you make games and play them
  with Test; Publish, the lobby link and the players list are not shown (a game published before can still be taken
  off). On a Connected gateway nothing changes.

0.1.5 (2026-11-16)
- Asking for changes to a game: the box now says what to write, and pressing a button with the box empty tells you to write
  the change first (before, nothing seemed to happen). After that the page moves to the new job and its steps.
- Author is now shown as "2nfro" (was "Bot Gateway")

0.1.4 (2026-11-09)
- Making a game in an AI tool: the job card now shows the steps one by one, with a picture of which folder to choose
  (myarcade-job-..., not the whole project). If you choose the whole project, only that folder is taken; if the folder
  you chose doesn't hold it, the card says so and nothing is sent.

0.1.3 (2026-11-06)
- The prompt you copy now tells the AI tool where to work, how to test the game without MyArcade, and what to do if it can't make image
  files or write files at all. The page reminds you to open an empty project in the tool first.

0.1.2 (2026-11-06)
- Make a game in any AI tool, also when your gateway's client is a remote bot: copy the whole prompt, paste it into Cursor or
  another tool, and choose the folder it made. No connection and no settings needed. The checks run at once; if they find problems
  you can copy a fix prompt. The same for changes to a game. A tool connected by MCP can still use the one line, with progress.

0.1.1 (2026-11-06)
- Making a game: pressing a Make button with an empty description now tells you to describe the game first (before, nothing seemed
  to happen), and the page moves to the new job, where "Make it in my IDE" shows the line to copy.

0.1.0 (2026-11-06)
- First version: your own public web arcade. Describe a game on your local page and your assistant or IDE makes it; test it, and
  publish it if you like it. Visitors sign up, play, and see play counts and leaderboards. Two demo games are included, not
  public until you publish them. Needs gateway 1.1.27 or newer.
