MyArcade - change log
The top section is the coming version (no date): write each change below it as "- ...", in words
for the gateway owners - the Portal and the gateway show them as "What's new" before an update.
store_update.sh --package myarcade publishes it (dated) and puts the next patch version on top; change
the top version by hand for a bigger step (e.g. 1.0.0). This file is not packed into the package.

0.1.3 (2026-11-06)
- The prompt you copy now tells the AI tool where to work, how to test the game without MyArcade, and what to do if it can't make image
  files or write files at all. The page reminds you to open an empty project in the tool first.

0.1.2 (2026-11-06)
- Make a game in any AI tool, also when your gateway's client is a remote bot: copy the whole prompt, paste it into Cursor or
  another tool, and choose the folder it made. No connection and no settings needed. The checks run at once; if they find problems
  you can copy a fix prompt. The same for changes to a game. A tool connected by MCP can still use the one line, with progress.

0.1.1 (2026-11-06)
- Making a game: pressing a Make button with an empty description now tells you to describe the game first (before, nothing seemed
  to happen), and the page moves to the new job, where "Make it in my IDE" shows the line to copy.

0.1.0 (2026-11-06)
- First version: your own public web arcade. Describe a game on your local page and your assistant or IDE makes it; test it, and
  publish it if you like it. Visitors sign up, play, and see play counts and leaderboards. Two demo games are included, not
  public until you publish them. Needs gateway 1.1.27 or newer.
